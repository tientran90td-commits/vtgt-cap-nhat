# vtgt-cap-nhat
Ban cai va goi cap nhat cua game Vuc Tham Giao Thoa (khong chua ma nguon)

## 🎥 Movie Recap AI

Thư mục [`MovieRecapAI/`](MovieRecapAI/) chứa app máy tính tóm tắt phim dài thành video ngắn bằng AI
(nhận dạng thoại Whisper, AI viết kịch bản, hơn 1000 giọng đọc, dựng video bằng FFmpeg).
Xem hướng dẫn tại [MovieRecapAI/README.md](MovieRecapAI/README.md).

## 📱 Trên điện thoại

- [`ReviewPhim/`](ReviewPhim/) - app Android (APK): review / tóm tắt phim, dịch thuyết minh + Vietsub.
  Tải: [ReviewPhim.apk](https://github.com/tientran90td-commits/vtgt-cap-nhat/releases/download/reviewphim/ReviewPhim.apk)
- [`Termux/`](Termux/) - bản chạy trong Termux, giao diện web trong Chrome, dùng lõi VietDub.
  Cài: `curl -fsSL https://raw.githubusercontent.com/tientran90td-commits/vtgt-cap-nhat/claude/movie-summary-app-0q90dq/Termux/install.sh | bash`
