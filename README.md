# vtgt-cap-nhat
Ban cai va goi cap nhat cua game Vuc Tham Giao Thoa (khong chua ma nguon)

## Caro Tro Thu (app Android)
Thu muc `caro-tro-thu/` chua app ho tro choi co caro (APK tu dung bang GitHub Actions, tai o muc Releases, ban `caro-tro-thu-apk`). Xem `caro-tro-thu/README.md`.

## Caro LIVE va Co vua LIVE (tool cho TikTok LIVE)
Thu muc `caro-live/` va `co-vua-live/`. Hai tool nay tu cap nhat tu thu muc nay (nut "Cap nhat phan mem" tren bang dieu khien).
Moi lan sua tool, tang so `version` trong `version.json` cua thu muc do thi tool o may nguoi dung moi thay co ban moi.
